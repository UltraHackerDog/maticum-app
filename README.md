# Maticum

Mathe und Physik üben ohne Papier, auf Deutsch: **https://ultrahackerdog.github.io/maticum-app/**

Dieses Repository enthält nur die gebaute Web-App. Der Quellcode ist nicht öffentlich. Die App lädt
nur ihre eigenen Dateien; was du löst, speichert sie nur in deinem Browser und schickt es nirgendwohin.
